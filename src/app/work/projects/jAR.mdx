## Overview

In this project, I focused on conducting user research and proposing redesign recommendations for the Jar app, a micro-savings platform. The goal was to identify pain points, analyze user behavior, and propose solutions to enhance usability and engagement. The recommendations aimed to address critical usability issues, improve the user experience, and streamline navigation within the app.

## Key Features

- **Usability and Design Flaws Identification**: Analyzed the existing app to identify key usability issues, such as excessive pop-ups, unclear navigation, and problematic feature access (e.g., locating coupons).
- **User Behavior Analysis**: Conducted in-depth research on user behavior within the app to identify pain points, engagement drops, and friction areas.
- **Redesign Recommendations**: Suggested solutions to improve the app’s usability, such as enhancing the in-app help section, simplifying feature navigation, and eliminating unnecessary restrictions like lock-in periods.
- **User Flow Optimization**: Created optimized user flows and personas to guide the redesign, ensuring the app caters to user needs while enhancing overall usability and engagement.

## Technologies Used

- **Survey Tools**: Google Forms for gathering user feedback and identifying pain points.
- **Design Tools**: Figma for creating wireframes and high-fidelity mockups of the redesigned interface.
- **Research Sources**: User reviews, app store feedback, and personal usage to gather insights and create personas.

## Challenges and Learnings

One of the biggest challenges was ensuring that the design accurately captured the app’s core functionality while remaining simple and intuitive. This involved making design decisions that catered to a diverse user base with varying behavioral patterns and preferences. Managing edge cases like ensuring responsiveness and balancing design aesthetics with usability were key concerns. Additionally, ensuring that design changes were consistently aligned with the development team’s needs and maintaining a smooth handoff process presented its own set of challenge

## Outcome

One of the key challenges was addressing the app’s behavioral patterns and preferences, which varied across user groups. Balancing the need for simplicity while retaining the app’s core functionality required thoughtful design changes. Additionally, optimizing feature access and reducing user frustration while ensuring feature availability posed its own challenges.

---

The research and redesign recommendations resulted in a more intuitive user experience, addressing key usability issues and simplifying navigation. The proposed changes are expected to lead to increased user engagement, reduced frustration, and higher retention rates. This project emphasized the importance of user research and its role in driving successful app redesigns that align with user needs.
